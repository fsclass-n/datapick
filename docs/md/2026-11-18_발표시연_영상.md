## 결정 사항
- 내레이션: 신경망 합성 음성 `ko-KR-HyunsuMultilingualNeural`, 속도 −4% · 톤 −2Hz, 문장 단위 합성 + 0.35초 쉼, −16 LUFS.
  속도를 올려야 하는 장면은 대본을 줄여 모든 장면을 같은 속도(−4%)로 맞춤
- 시연 영수증은 가상 문서를 스캔 PDF 로 만들어 사용 → Gemini 멀티모달 경로로 거래처 · 품목 · 금액 정확히 추출(11~41초).
  이미지(PNG) 업로드는 Tesseract 경로라 60초 이상 걸리고 품목명을 일부 잘못 읽어 시연에서 제외
- 서버의 Playwright 로봇은 화면이 없으므로, `rpa/erp_typer.py` 의 같은 셀렉터 맵으로 데모 ERP 화면에서 입력을 재현해 보여 주고 대본 · 태그로 명시
- 발표자료를 개편 후 기준으로 갱신: pytest 30개, 테스트 관리자 = 조회 전용, 화면 캡처를 운영 서비스에서 다시 촬영(`docs/scripts/capture_screens.py`)
