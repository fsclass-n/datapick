# 2026-11-24 운영 관리자 이메일·비밀번호 로그인 전환 + 시연용 샘플 자료

## 운영 관리자 로그인: 토큰 → 이메일·비밀번호
- **배경**: 기존에는 `/admin/login` 에서 서버 환경 변수 `ADMIN_TOKEN` 을 입력하는 방식이라, 일반적인 "이메일+비밀번호 로그인" 경험과 달랐다.
- **변경**: `ADMIN_TOKEN` 폐기 → `ADMIN_EMAIL` + `ADMIN_PASSWORD` 조합으로 변경.
  - `POST /api/auth/admin-login` 이 `LoginIn`(email+password)을 받아 환경 변수와 `compare_digest` 비교. 실패 시 같은 메시지(401), 5회 실패/10분 차단·미설정 503 은 동일.
  - 인증 성공 시 `ADMIN_EMAIL` 계정을 생성·승격(`role=admin`, `provider="admin"`)하고 비밀번호 해시를 환경 변수 값으로 갱신 → **같은 이메일·비밀번호로 일반 로그인 화면에서도 접속 가능**.
  - `seed_admin_account()`(main.py lifespan): 기동 시 환경 변수가 있으면 계정 준비 + 권한 부여 → `/admin/login` 을 거치지 않아도 일반 로그인으로 바로 진입 가능. 공개 테스트 계정 이메일과 겹치면 시드하지 않음.
  - `/api/auth/providers` 키 `admin_token` → `admin_login`.
- **관리자 지정**: 기존 `PATCH /api/admin/users/{id}/role`(`role=admin`)과 회원 관리 토글로 다른 회원을 운영 관리자로 지정 가능(이미 구현되어 있어 유지). 테스트 계정·본인 권한 해제 차단 규칙도 그대로.
- **수정 파일**: config.py, schemas.py(AdminLoginIn 삭제), routers/auth.py, main.py, AdminLogin.jsx(이메일+비밀번호 폼), AuthContext.jsx, Home.jsx, format.js, mock.js, conftest.py, test_api.py, .env.example, render.yaml, readme.md.
- **검증**: pytest 31개 통과(일반 로그인으로 관리자 진입 테스트 추가), lint 오류 0, build 성공.
- **운영 적용 시 할 일**: Render 대시보드에 `ADMIN_PASSWORD` 등록(`render.yaml` `sync: false` 이미 선언) + 기존 `ADMIN_TOKEN` 제거. `ADMIN_EMAIL` 은 `operator@datapick.io` 고정 값.
