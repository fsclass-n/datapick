## 설계 원칙: AI는 읽기만, 판정은 규칙 코드
- Gemini 는 구조화 출력(Pydantic 스키마)으로 **값과 원문 발췌만** 돌려준다. 비교 · 점수 · 판정은 `services/analyzers.py` 순수 함수가 계산 → 같은 입력이면 같은 결과, 테스트 가능
- `GEMINI_API_KEY` 가 없으면 정규식 규칙 추출기로 동작(텍스트가 있는 문서만, 스캔본 · 사진은 422 안내)
- Gemini 호출부는 `parser.generate_structured(prompt, schema, …)` 로 공용화(기존 429/5xx 백오프 재시도 테스트 3개 그대로 통과)

## 트러블슈팅
- **어순이 다른 품목 미매칭**: '도장(문틀)' ↔ '문틀 도장' 의 문자 순서 유사도 0.5 → 2글자 조각 dice(0.67) 병행
- **PDF 줄바꿈으로 문장 조각화**: 샘플 PDF 의 줄바꿈 때문에 발췌문이 '위약금으로 갑에게 지급한다.' 처럼 잘림 → 조항 본문을 마침표 기준으로 자르고 공백을 정규화
- **줄바꿈을 못 건너는 규칙**: `[^.\n]{0,20}` 이 줄바꿈에서 끊겨 '사전 통보 없이 … 변경' 을 놓침 → `[^.]{0,20}` 으로 수정
- **'책임도 지지 않는다' 미탐지**: `책임[을도은]?\s*지지\s*않` 으로 보강
- **heredoc 백슬래시 손실 · 긴 명령 잘림**: 셸 heredoc 이 `\n` 을 실제 줄바꿈으로 바꾸고 긴 파일은 중간에 끊겨, 큰 파일은 편집 도구로 작성
- **새로고침 후 시각 9시간 이르게 표시(이전 미해결 건)**: DB 가 시간대 없는 UTC 값을 돌려주는 것이 원인 → `schemas.UtcDatetime` 으로 응답 시각에 UTC 표시, `stats` 의 최근 실패 시각도 동일 처리, 회귀 테스트 추가

- **운영 배포 후 Gemini 응답 점검에서 발견**: 계약서 발췌문 한 글자 변형('필요한' → '필요할')으로 빨간 줄 위치를 못 찾음(카드로만 표시되는 안전 동작), 위약금 조항을 '일방 해지'로 · 자동 연장을 '주의'로 분류, 비밀유지 조항 누락 → `merge_with_rules`: AI 발췌문의 유형 · 위험도는 규칙으로 다시 판정하고 AI 가 놓친 규칙 조항을 추가, `_locate` 에 유사도 0.85 이상 원문 문장 대체 탐색. 실제 응답을 재현한 회귀 테스트 추가(총 50개). 견적 비교 · 검진 추이는 운영 Gemini 결과가 규칙 엔진과 동일(총액 · 최저가 · 이상 단가 2건 · 빠진 품목 / 나빠진 9 · 좋아진 1)

## 브랜드 · UI 개편
- 팔레트: 잉크 남색(`ink` #14213d, `brand-*`) · 금박(`gold-*` #e9a23b) · 종이 배경(`paper` #f7f5f0). 도구별 강조색 sky · rose · emerald
- 로고: 깃펜의 한쪽 깃이 금색 데이터 픽셀로 흩어지는 마크(시안 4종 → 2차 다듬기 후 확정), 워드마크 data(남색) + quill(금색). 앱 · 파비콘 · GitHub Pages 동일 적용
- 홈: 히어로(깃펜 사진 + 4개 결과 미리보기 자동 전환) → 샘플 결과 요약 띠 → 서비스 카드 4종(사진) → 작동 방식(읽기 · 판정 · 결과) → 개인정보 · 권한 → FAQ → CTA
- 헤더: 로그인 후 'AI 도구' 드롭다운(모바일 서랍은 그룹 목록), 푸터: 잉크 배경 + 서비스 링크 + 사진 출처
- 도구 페이지 공통 셸(`components/tools/ToolPage.jsx`): 사진 히어로 · 업로드(드래그 · 다중 · 붙여넣기) · **샘플로 바로 체험** · 최근 분석 · 결과
- 대시보드: AI 도구 런처 + 최근 AI 분석, 문서 자동 입력 화면도 같은 히어로 사용
- 개인정보처리방침: AI 도구 원본 미저장 · 민감 정보 주의 조항 추가
