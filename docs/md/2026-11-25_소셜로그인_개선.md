# 2026-11-25 소셜 로그인 개선

## 배경
- SNS 로그인 버튼 클릭 후 완료하지 않고 뒤로가기하면 스피너·비활성 상태가 그대로 남아 멈춘 것처럼 보임
- Google 버튼 클릭 시 `dataquill-api.onrender.com/api/auth/oauth/google/login` 에서 Chrome "위험한 사이트" 차단 페이지가 뜸

## 원인
- `socialLogin` 이 `setBusy(provider)` 후 `location.assign` 으로 외부 페이지로 이동 → 뒤로가기 시 브라우저가 bfcache 에서 페이지를 복원해 React `busy` 상태가 그대로 남음
- Google Safe Browsing 가 `…/oauth/google/login` URL 을 위험 사이트로 등록 (다른 도메인에서 `google/login` 경로는 피싱 패턴으로 분류되기 쉬움). 도메인 전체가 아니라 해당 URL 단위로 플래그된 것으로 보임(`/docs` 는 정상 표시)

## 변경
- `GET /api/auth/oauth/{provider}/login` → `/api/auth/oauth/{provider}/start` 로 경로 변경 (콜백은 Google 콘솔 등록 그대로 `/callback` 유지)
- 같은 엔드포인트에 `?format=json` 추가 → 리디렉션 대신 `{ "url": "<제공자 인증 URL>" }` 반환 (state 쿠키는 동일하게 설정)
- `Login.jsx` `socialLogin`: `credentials:'include'` fetch 로 시작 URL을 받은 뒤 주소창 이동은 제공자(Google/Naver/Kakao) 페이지로 직접 수행 → 플래그된 API URL 이 탐색 경로에 나타나지 않음. 실패 시 기존 리디렉션 방식으로 폴백
- `Login.jsx`: `pageshow`(bfcache 복원)·`visibilitychange`(탭 복귀) 이벤트에서 `busy` 해제
- 버튼 호버 손가락 커서: `index.css` 전역 `button:not(:disabled){cursor:pointer}` (이전 커밋)
