# 2026-11-25 프로젝트명 dataquill → datapick 변경

## 배경

- 배포 도메인을 `datapick.netlify.app` · `datapick.onrender.com` · `datapick.duckdns.org` 로 변경함에 따라 저장소·코드·문서의 프로젝트명을 일괄 변경.

## 변경 범위

### GitHub
- 저장소 `fsclass-n/dataquill` → `fsclass-n/datapick` (`gh repo rename`). GitHub Pages 주소도 `fsclass-n.github.io/datapick/` 로 자동 변경됨.
- 로컬 `origin` URL을 새 주소로 교체. (구 주소는 GitHub가 자동 리다이렉트하지만 GitHub Pages는 리다이렉트되지 않으므로 링크를 모두 수정함)

### 코드·설정 (git 추적 텍스트 파일 45개 + .env 일괄)
- 치환 규칙: `dataquill`→`datapick` · `DataQuill`→`DataPick` · `dataQuill`→`dataPick` · `DATAQUILL`→`DATAPICK` · `데이터퀼`→`데이터픽` · `dq_mock_db_v2`→`dp_mock_db_v2`
- 워드마크 `data`(ink) + `pick`(gold) — 분할 지점이 같아 로고 마크·색 분리 그대로 유지
- 도메인: `datapick.onrender.com`(프런트) · `datapick-api.onrender.com`(API) · `datapick.netlify.app` · `datapick.duckdns.org`(CORS 추가)
- `render.yaml`: 서비스명 `datapick-api`/`datapick`, `ADMIN_EMAIL`→`operator@datapick.io`, `CORS_ORIGINS`에 netlify·duckdns 도메인 추가
- 테스트 계정 이메일 `user@/admin@datapick.io`(백엔드 시드 + mock.js + 테스트 동기화). 기존 운영 DB의 @dataquill.io 계정은 그대로 남음
- 로컬 SQLite `storage/dataquill.db` → `storage/datapick.db` (config 기본값과 일치)

### 그 외 수정
- `App.jsx` OAuth 콜백의 effect 내 동기 setState → `setTimeout`으로 지연(상위 커밋에서 온 lint 오류 1건 해소. CI가 lint를 돌리므로 필요)
- `.env`: FRONTEND_URL/BACKEND_URL/CORS_ORIGINS/ADMIN_EMAIL·주석을 새 도메인으로. `DATABASE_URL`의 TiDB DB명 `dataquill`은 실제 DB 이름이라 유지

## 변경하지 않은 것 (재생성 필요)
- `docs/video/*.mp4`(내레이션에 '데이터퀼' 발음), `docs/pdf/프로젝트_발표자료.pdf`, `docs/*.hwpx`, `docs/video/3조_final.srt`는 텍스트는 치환했으나 mp4·pdf·hwpx 바이너리는 이전 명칭 그대로 → 영상·발표자료 재제작 시 반영됨
- TiDB 데이터베이스명 `dataquill` (DB 이관이 필요해 유지)
- 배포 플랫폼 대시보드의 환경 변수(Render `BACKEND_URL`·`CORS_ORIGINS`·OAuth 콜백 URI, Netlify `VITE_API_URL`, Google/Naver/Kakao 콘솔 Redirect URI)는 대시보드에서 직접 변경해야 함
