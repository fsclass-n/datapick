# 2026-11-17 1차 구현 (프런트엔드 + 백엔드·RPA 골격)

## 범위
- 1단계(프런트엔드)를 완성하고, 실제 OAuth 연동에 필요한 백엔드·RPA·AI 파이프라인을 함께 구현
- 배포 설정(Netlify / Render / GitHub Actions / Docker) 파일 작성 (실제 배포는 미실행)

## 구현 내용

### 백엔드 (FastAPI, `backend/app`)
| 영역 | 내용 |
| --- | --- |
| DB | SQLAlchemy 2.0, 기본 SQLite / `DATABASE_URL` 로 TiDB(MySQL) 전환, `DB_SSL` 시 certifi CA 사용 |
| 모델 | `users`, `documents`, `rpa_jobs` |
| 인증 | JWT(HS256), PBKDF2 비밀번호 해시, 비밀번호 규칙(영문 대·소문자+숫자+특수문자 8자 이상) 서버 검증 |
| OAuth | Google / Naver / Kakao Authorization Code 흐름, state 쿠키 CSRF 검증, 이메일 중복 가입 차단 |
| 문서 | 업로드(10MB, PDF·이미지·EML·HTML·TXT), 이메일 본문 입력, 검수 수정(PATCH), 재해석, 삭제 |
| AI 파싱 | Gemini 구조화 출력(response_schema), 이미지·스캔 PDF는 멀티모달 / 키가 없으면 규칙 기반 파서 |
| RPA | 엑셀 원장 적재(pandas+openpyxl), Playwright ERP 자동 타이핑, 데모 ERP 화면 `/erp-demo` |
| 관리자 | 회원 목록·검색·권한 변경(본인 강등 차단), 통계 API(파싱 성공률·RPA 성공률·일별 추이) |

### RPA (`rpa/`)
- `extract.py`: PDF 텍스트, Tesseract OCR(설치 시), 이메일(EML) 본문, HTML → 텍스트
- `excel_writer.py`: 문서 ID 기준 upsert 방식 엑셀 원장
- `erp_typer.py`: 셀렉터 기반 ERP 입력, CLI 단독 실행 지원

### 프런트엔드 (`frontend/`)
- React 19 + Vite 8 + Tailwind CSS v4 + FontAwesome 7 + Recharts 3
- 폰트 이원화: 제목 IBM Plex Sans KR / 본문 Pretendard
- 로그인: Split 레이아웃(좌측 브랜드 그래픽), 테스트 계정 원클릭 로그인, Google/네이버/카카오 버튼, 비밀번호 규칙 실시간 체크, 회원가입 전환
- 모바일 GNB: 햄버거 ↔ X 전환 애니메이션, 우측→좌측 드로어 슬라이드(백드롭, ESC, 스크롤 잠금)
- 대시보드: KPI 카드, 일별 처리 추이, 소스 분포, 최근 문서
- 문서 처리: 드래그&드롭 업로드 / 이메일 본문 탭, 추출 결과 검수, 엑셀 적재·ERP 타이핑, 작업 이력
- 관리자: 회원 관리(검색·필터·권한 토글), 모니터링(성공률 게이지, 일별 차트, 분포 도넛, 최근 실패)
- 공통: 'To the Top' 버튼(푸터 + 스크롤 시 플로팅, smooth scroll), 토스트 알림, 페이지 코드 스플리팅
- Mock 모드: `VITE_API_URL` 미설정 시 localStorage 목업 API (1단계 Netlify 단독 배포용)

### 인프라
- `.env.example`: [LOCAL] / [RENDER] / [NETLIFY] 구분 표기, Vite `envDir: '..'` 로 루트 `.env` 단일 관리
- `backend/Dockerfile`(Tesseract 한국어 + Playwright Chromium), `frontend/Dockerfile`(nginx), `docker-compose.yml`

## 이슈 및 해결
- `.env` 에서 빈 값 뒤 인라인 주석이 값으로 읽히는 문제 → 주석을 별도 줄로 분리
- Tailwind v4 에서 `@layer components` 클래스는 `@apply` 불가 → `@utility` 로 정의
- 헤더 `backdrop-filter` 가 fixed 드로어의 기준 박스가 되는 문제 → 드로어를 헤더 밖으로 분리
