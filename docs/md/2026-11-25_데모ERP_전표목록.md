# 2026-11-25 데모 ERP 전표 목록 화면 추가

## 배경

- 'ERP 자동 타이핑' 실행 결과가 전표번호 문자열(토스트·작업 이력)뿐이라, 실제로 ERP에 저장됐는지 눈으로 확인할 화면이 없었다.
- 엑셀 원장은 다운로드로 결과를 확인할 수 있는 것과 대비되는 공백.

## 변경

### 데모 ERP 페이지 개편 (`backend/app/routers/erp_demo.py`)

- 단일 입력 폼 → **좌: 매입 전표 입력 폼 / 우: 전표 목록** 2단 구성, 상단에 "Demo ERP" 헤더 바.
- 전표 목록 테이블: 전표번호 · 거래일자 · 거래처 · 사업자번호 · 합계금액 · 부가세 · 적요, 최신 전표가 위.
- **3초 간격 자동 갱신** — DataQuill 앱에서 RPA를 실행하면 이 화면을 열어둔 채 새 전표가 나타나는 것을 볼 수 있다(시연용). 새로 들어온 전표는 인디고 배경으로 하이라이트.
- 목록 렌더링은 문자열 이스케이프 처리(XSS 방지).
- **Playwright 선택자는 그대로 유지** — `#vendor` `#business_number` `#date` `#total_amount` `#vat` `#summary` `#submit`, 결과는 `#result[data-status]` + `data-voucher`. `rpa/erp_typer.py` 수정 없음.

## 검증

- pytest 50개 통과(`test_erp_demo_voucher`에 "전표 목록" 표시 확인 추가).
- 로컬 서버(:8011)에서 `erp_typer`로 2건 입력 → 전표번호 `JV-20261125-0001/0002` 발급, 목록에 표시되는 것을 화면 캡처로 확인.
