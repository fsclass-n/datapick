## 테스트 순서

1. https://datapick.onrender.com 접속 → 로그인 화면에서 **일반 사용자** 버튼 클릭(자동 로그인)
2. **문서 처리** 메뉴 → 파일 업로드 또는 드래그 → AI 추출 결과(필드 + 신뢰도) 확인
3. 잘못 읽힌 필드는 수정 후 **저장** → **엑셀 적재** 또는 **ERP 입력** 실행
4. 작업 이력에서 결과 확인 — ERP 입력은 데모 ERP 가 발급한 **전표번호가 찍혀야 성공**
5. 같은 문서를 엑셀에 여러 번 적재해도 원장에 **1행만** 유지되는지 확인(엑셀 원장 다운로드로 확인)
6. 대시보드에서 KPI · 최근 14일 추이 변화 확인

## 참고

- `02` `.eml` 업로드 대신, 메일 본문 텍스트를 **메일 본문 붙여넣기**로 넣어도 같은 결과입니다.
- 이메일 가입, Google · Naver · Kakao 소셜 로그인도 실제로 동작합니다(새 계정은 본인 문서만 보임).
- **테스트 관리자**(로그인 화면의 다른 버튼)로 로그인하면 관리자 화면을 조회할 수 있지만, 업로드 · 수정 · RPA 실행은 전부 403으로 차단되는 것도 확인할 수 있습니다.
- 테스트 계정은 공개 계정입니다. **실제 문서나 개인정보는 올리지 마세요.** 업로드 문서는 다른 체험자에게 보일 수 있고 AI 해석을 위해 Google Gemini API 로 전송됩니다.
