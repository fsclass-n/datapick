DataQuill은 영수증 · 세금계산서 · 거래 이메일처럼 형식이 제각각인 문서를 OCR + Gemini로 정형화하고, 사람이 검수한 값을 Playwright 로봇이 ERP 전표 화면과 엑셀 원장에 대신 입력하는 B2B 자동화 서비스입니다. 같은 읽기 엔진으로 만든 견적서 비교 · 계약서 빨간펜 · 건강검진 추이 도구도 함께 제공합니다.

01
Problem · 왜 만들었나

같은 값을, 두 번, 손으로

경리 · 총무 담당자는 영수증과 청구 메일을 보고 ERP에 한 번, 엑셀 원장에 또 한 번 입력합니다. 자동화가 어려웠던 이유를 로그로 정리했습니다.

09:02INFO메일함에 청구서 12건, 스캔 영수증 31장 도착
09:05WARN문서마다 양식이 다름 → 규칙(정규식) 추출 실패
09:40WARNERP 화면에 수기 입력 중 · 오타 2건
10:15WARN같은 값을 엑셀 원장에 다시 입력 · 불일치 1건
10:16ERRORERP 연동 API 없음 → 사람 말고는 입력 수단 없음
10:16PLAN해석은 생성형 AI, 입력은 RPA, 그 사이에 사람 검수

※ 문제 상황을 설명하기 위한 예시 로그입니다.

비정형 입력

영수증 · 세금계산서 · 청구 메일마다 형식이 달라 규칙 기반 자동화가 쉽게 깨집니다.

반복 · 이중 입력

같은 거래를 ERP와 엑셀에 따로 입력해 시간이 들고 값이 어긋납니다.

API 없는 레거시 ERP

연동 API가 없으면 결국 누군가 화면에 직접 타이핑해야 합니다.

해석은 생성형 AI→ 사람의 검수 단계→ 입력은 RPA 로봇 AI가 틀릴 수 있기 때문에 검수(Human-in-the-loop)를 일부러 넣었습니다.

    05
    Access control · 권한 매트릭스

    버튼을 숨기는 건 편의, 경계는 서버

    세 역할의 권한을 API 단일 진입점(deps.get_current_user)에서 검사합니다. 새 API를 추가해도 같은 규칙이 자동으로 적용됩니다.

    동작 운영 관리자ADMIN_TOKEN 인증 테스트 관리자공개 계정 · 읽기 전용 일반 사용자가입 · OAuth · 테스트 계정
    쓰기 요청 일괄 차단

    test_admin 의 GET · HEAD · OPTIONS 외 요청은 403. 화면의 비활성 버튼과 별개로 서버가 막습니다.

    공개 계정 권한 고정

    비밀번호가 공개된 테스트 계정은 권한 변경 API로 바꿀 수 없고, 서버 기동 시마다 원래 권한으로 복원됩니다.

    토큰 로그인 보호

    compare_digest 비교, 같은 IP 5회 실패 시 10분 차단, 토큰 미설정 시 운영 관리자 로그인 비활성.
